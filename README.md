### 해결한 것
1. 탭 메뉴 디자인 적용 안되는 문제
    * 선택자의 오타가 있었음
    * 처음에 class로 지정하여 디자인하였는데 JS작성과정 중 헷갈릴 것 같아 일단 개별로 작성해둠
2. 화면크기를 줄일때 상품이 겹치는 문제
    * swiper의 너비 고정, swiper-slide 너비 고정하여 해결 
    * 피그마에서 간격 잘못 확인하였고 slide가 아닌 그 자식에게 너비를 주었음
3. 데일리 컬렉션의 상품 스와이퍼 작동 안되는 문제
    * 스와이퍼의 관한 공부내용과 AI에게 궁금한 내용을 물어보아 swiper 속성 grid로 해결
    * 2행 3열 구조로 만들기 위해서는 슬라이드 내에 여러 상품을 두고 나열하는 방법과 속성을 이용한 방법이 있음을 알게 됨
4. 가로 무한 스크롤? -ok
    * 스와이퍼에 너비 고정으로 인해 화면 크기가 줄었을때 그 크기가 유지되어서 발생
    * max-width와 width:100%로 변경 -> 해결이 완벽하게 된건지는 잘 모르겠다. 
5. 탭메뉴 클릭 시 해당 스와이퍼 상품 레이어 나오도록하는 JS
    * 탭 메뉴의 경우 쉽게 해결함 / swiper의 경우 AI의 도움을 받아 해결하였음
    * 해결 방법
    1. 탭 메뉴, swiper 기본 CSS와 `.active`일 때의 CSS 준비
        * 탭 메뉴는 디자인 지정
        * `swiper`는 `display:none;`으로 모두 숨기고 `swiper.active`일 때만 `display:block;`으로 보이도록 함
    2. 탭 메뉴와 swiper의 변수 준비
    3. 탭메뉴 클릭시 swiper가 나오는 것은 반복되는 것이므로 function과 for 사용
        * fuction 안에서 매개변수를 사용하여 다른 탭-swiper 구조에서도 사용 가능하도록 함
        * forEach를 사용하여 탭의 오브젝트를 클릭하도록 하고 그 클릭한 오브젝트의 인덱스 번호를 사용하여 활성화할 스와이퍼를 결정짓는다.
    4. 탭 메뉴의 태그를 `a`로 설정하여 클릭 이벤트 시 페이지 상단으로 스크롤 되는 동작 제거 
        * `(e)=>{e.preventDefault();...}`
    5. 기본적으로 active는 클릭 전에 모두 초기화시킨 상태에서 적용되도록 해야한다.
        * `resetFunc(tabB); o.classList.add('active');`
    6. display:none;상태였던 swiper는 너비와 위치 계산이 초기화될 수 있어 display:block 시 스와이퍼에 대한 정보를 갱신해줘야한다.
        * if(swiperList[i]){swiperList[i].update();}
        * 해당 인덱스 번호에 실제로 스와이퍼 객체가 들어있을때만 업데이트하라
6. 서브 메뉴 JS 생성 - 동일하지 않은 구성
7. nav 호버 시 나오는 서브메뉴  JS
    * nav 호버 시 서브메뉴로 가는 도중 꺼지는 문제 발생 
        * 선택되는 대상인 a와 나오는 대상인 ul(wrap) 사이에 공백이 있어 a에서 벗어나면 없어지게 되는데 이는 header에 여백을 주어 생긴 문제로 공백을 없애고 a에 line-height를 주어 header의 높이와 맞춰서 해곃
